# src/assets — shipped media (hashed)

Audio sprites, fonts, and images that ship with the game. They're imported from code or CSS, so Vite content-hashes them into `/assets/` (which `vercel.json` caches as immutable, D-029).

**Every file here needs a row in `docs/ASSETS.md`** (source, author, licence, date). No CC BY-NC, BBC, or share-alike assets.
